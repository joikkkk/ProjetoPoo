# Sistema de Biblioteca

Projeto acadêmico de Programação Orientada a Objetos para gerenciar o acervo e os empréstimos de uma biblioteca escolar.

## Funcionalidades

- Cadastrar e remover livros, revistas e DVDs
- Cadastrar e remover alunos e professores
- Realizar empréstimos e devoluções
- Calcular multas por atraso
- Consultar itens, usuários e empréstimos ativos

## Tecnologias

- Java
- Spring Boot
- Thymeleaf
- HTML e CSS

## Conceitos de POO

O projeto utiliza classes, herança e polimorfismo para representar os tipos de itens e usuários. Também usa a interface `Exibivel` para apresentar informações de diferentes objetos.

## Como executar

Abra o projeto na sua IDE e execute a classe `DemoApplication`. Depois, acesse:

http://localhost:8080

> Os dados são mantidos em memória e podem ser reiniciados ao encerrar a aplicação.

## Estrutura

- `src/main/java`: classes Java e lógica da aplicação
- `src/main/resources/templates`: páginas HTML
- `src/test/java`: testes

## Observação

O projeto também possui uma versão de console iniciada pela classe `SistemaBiblioteca`.
